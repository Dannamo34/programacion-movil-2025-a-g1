# HU-07: Creación de base de datos e inserción de datos iniciales

## Descripción
Como desarrollador, necesito crear la base de datos y las tablas correspondientes, así como insertar registros de prueba, para que la aplicación tenga una estructura mínima funcional y pueda ejecutarse correctamente en entornos locales o de pruebas.

## Criterios de Aceptación
- Criterios de Aceptación:

Crear la base de datos llamada rutinas mediante CREATE DATABASE rutinas.

Usar SHOW DATABASES para verificar su existencia.

Insertar datos de prueba en las tablas creadas.

- ✅ Crear la base de datos llamada `rutinas` usando:
  ```sql
  CREATE DATABASE rutinas;
